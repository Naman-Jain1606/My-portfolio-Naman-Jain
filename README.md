## ⚡ How to Run & View Locally

### Option 1: Open Directly in Any Web Browser
Double-click `index.html` or right-click and select **Open with Google Chrome / Microsoft Edge / Brave / Firefox**.

### Option 2: Run with VS Code Live Server
1. Open the folder `MY PORTFOLIO` in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.
3. The site will run live at `http://127.0.0.1:5500`.

### Option 3: Run via Python Local Server
Run in PowerShell / Terminal:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## 🌐 How to Deploy for Free

### 1. GitHub Pages
1. Create a new repository on GitHub named `naman-portfolio`.
2. Push all files from `MY PORTFOLIO/` to the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Avengers Portfolio"
   git branch -M main
   git remote add origin https://github.com/namanjain1606/naman-portfolio.git
   git push -u origin main
   ```
3. Go to **Settings > Pages > Source** and select `main` branch. Your website will be live at `https://namanjain1606.github.io/naman-portfolio/`!

### 2. Vercel or Netlify
- Drag and drop the `MY PORTFOLIO` folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com) for instant deployment with free HTTPS and custom domain support!
